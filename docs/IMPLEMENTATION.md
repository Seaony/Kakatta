## M1 实现范围

- Docker 镜像使用官方 Chrome、Xvfb、x11vnc 和嵌入的 noVNC 静态文件；入口修正数据目录属主后降权，支持 PUID/PGID 和指定用户。默认保留沙盒，另外提供命名空间 seccomp 规则。

- `cmd/experiment` 将扫码登录和单次搜索分开；一次搜索依序走首页、中文输入、筛选和两三个详情，记录元素与解析字段。额度、间隔、验证、冷却、拒绝暂停和时间保护持久化，损坏或写盘失败时停止。
- 筛选与人工登录所需选择器、接口片段和协议等待集中到带版本号的规则文件；补齐个人闲置、包邮、地区、价格、本地假页与等待策略。文档重取使 DOM 搜索会话失效时，文字与 XPath 查询最多完整重建三次，不注入脚本。

## M2 实现范围

- `cmd/kakatta` 为正式入口，镜像保留可显式选择的 `experiment`。先生成并嵌入网页静态资源，运行镜像不含构建工具。主密钥先于数据库准备，原子写入和同步；显式来源不回退，已有数据库而默认密钥丢失时拒绝补造。容器内维护命令从无回显终端或标准输入读取新密码，不把密码放在命令行。
- SQLite 使用 WAL、每连接外键和 5000 毫秒等待、FULL 同步及单连接池；初始迁移覆盖完整数据模型。旧库升级前生成一致快照，只保留最近三份本程序命名的升级备份；全部迁移同事务，未知、未来、跳号、损坏均拒绝打开。旧版本先迁移再核对新版列，失败回滚且不推进版本。
- 安全计算、管理员认证与 HTTP 分开。初始化令牌和验证码挑战仅在内存；密码、TOTP、会话、吊销和维护换代有事务校验。新接口令牌的最近使用时间为空，成功认证后才填写。正式会话遵守第 40 条，不沿用实验工具的短期会话规则。
- M2 的十九个接口操作有单一 OpenAPI 3.1 描述及生成类型。正常业务、描述和 SSE 验证会话或 Bearer；初始化、密码和验证码端点验证各自凭据。统一跨站保护、可信代理、登录节流、原因代码、字段错误和请求编号；严格 JSON 有大小、格式和读取时限。
