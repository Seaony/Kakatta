以 `PRODUCT.md`、`DECISIONS.md`、`CRAWL-POLICY.md`、`DOMAIN.md`、`XIANYU.md` 为规格。开发和测试只用本地页面、样例响应和假的外部服务，不访问闲鱼，不用真实账号。

## 目录

| 位置 | 职责 |
|---|---|
| `cmd/kakatta/` | 正式服务入口和容器内的管理命令 |

| `cmd/seed/` | 创建本地样例任务、商品和结果 |

| `internal/xianyu/web/` | 只读页面流程和风控检查 |
| `internal/xianyu/fake/` | 本地假页面，不包含外部资源 |
| `internal/pacer/`、`internal/quota/` | 随机等待和额度判断 |

| `internal/notify/` | 推送判定、发送队列和渠道适配 |

## M0 核对范围

完整读取了原有 `internal/` 的 31 个 Go 文件（含测试）和 11 份样例，并按三个规格文件逐一核对：

- `browser/chrome.go`、`procmem*.go`：保留 Chrome 查找和进程内存诊断；进程树 RSS 只能作诊断，不能当作容器实际内存。
- `browser/session.go`：改为账号固定端口、中文、固定窗口、时区和缓存配置；运行前检查旧进程和锁；正常关闭后清理进程组；导航等待匹配主框架和加载编号；网址读取使用协议命令。
- `browser/capture.go`：保留请求发出时编号；修正重定向、主文档处罚头、有界保存和并发快照；筛选等待在途请求和静默窗口。
- `browser/human.go`：保留鼠标、键盘、滚轮和无障碍输入值读取，修正节点查询和可见性检查；生产路径不执行页面脚本。
- `xianyu/envelope.go`、`parse_detail.go`、`parse_seller.go`：保留外壳、详情和卖家解析；待真实页面确认的字段继续明确标记，不能猜成已验证。
- `xianyu/parse_search.go`、`values.go`：保留逐商品容错、金额和时间换算；补原价原文、缺列表的结构错误，以及大整数精度修正。
- `xianyu/web/runner.go`、`risk.go`、`search.go`、`login.go`：修正已有流程的风控、超时、发布时间、关键词核对和本地登录预检；`detail.go`、`profile.go` 保留只读访问和错误外传的主体。
- `xianyu/fake/fake.go`：保留本地样例站点并补充回归场景；不加载外部资源。
- `pacer/pacer.go`：保留均匀随机等待和取消处理；`quota/quota.go` 保留纯额度判断，记录保留期改为 48 小时。
- 各目录原有测试保留并补上上述行为的回归。旧 `cmd/kakatta-probe/` 整体删除，不改名复用循环运行逻辑。

尚不存在的完整地区、价格和卖家页面流程由 M4 实现；独立虚拟屏幕、认证代理和远程画面由 M1 实现；持久化额度与第 64 条时间保护由 M3 集成。这些未实现项不能算作旧代码验收已经通过。

浏览器测试需要 Linux、正式版 Chrome 和可用的虚拟屏幕，在隔离网络的测试容器里显式运行 `KAKATTA_BROWSER_TESTS=1 go test -p 1 ./...`。`-p 1` 防止不同测试包争用同一个测试账号的固定端口；没有开关时集成用例会明确跳过。本机常规检查使用 `go build ./...`、`go test ./...`、`go test -race ./...` 和 `go vet ./...`。正式镜像和可复制的容器测试入口在 M1 交付。

## M1 实现范围

- Docker 镜像使用官方 Chrome、Xvfb、x11vnc 和嵌入的 noVNC 静态文件；入口修正数据目录属主后降权，支持 PUID/PGID 和指定用户。默认保留沙盒，另外提供命名空间 seccomp 规则。
- 每账号独立虚拟屏幕；本机 HTTP/SOCKS5 转发支持认证并让上游解析目的域名，失败不直连。远程静态文件与 WebSocket 全部认证，VNC 只监听回环。
- `cmd/experiment` 将扫码登录和单次搜索分开；一次搜索依序走首页、中文输入、筛选和两三个详情，记录元素与解析字段。额度、间隔、验证、冷却、拒绝暂停和时间保护持久化，损坏或写盘失败时停止。
- 筛选与人工登录所需选择器、接口片段和协议等待集中到带版本号的规则文件；补齐个人闲置、包邮、地区、价格、本地假页与等待策略。文档重取使 DOM 搜索会话失效时，文字与 XPath 查询最多完整重建三次，不注入脚本。
- 远程画面支持第一触点立即按下、连续拖动、1:1 显示、只平移画面和显式文字输入；保留第三方来源及许可证，补齐压缩流重置回归。人工阶段新拒绝会关闭窗口并持久化暂停。
- 宿主检查用 Go 构建、全部测试、竞态和静态检查，以及 `node --test internal/remote/*_test.mjs`。可复制的断网容器全包回归见 `deploy/test-container.sh`，分别覆盖默认与严格 seccomp；手动页面验收用有明确开关、七分钟后自动关闭的本地假页测试。

新增第 65–67 条技术决定，说明实验认证与账号保护、两档 WebGL 实测，以及人工登录恢复证据和拒绝状态替换。真实页面行为仍保留待确认标记。
