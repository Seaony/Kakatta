# 背景

## 从 Mekke 到 Kakatta

- Mekke（`~/code/Mekke`）是作者之前做的原生 macOS 闲鱼监控应用：SwiftUI + WKWebView，常驻菜单栏。做到约 188 个提交、3 万行 Swift 业务代码和 1.8 万行测试。
- 2026-11-10 作者判断「方式有问题」：监控更适合跑在服务器的 Docker 里，24 小时运行、发现合适的就推送；只有 Mac 端不够，Mac 只能是其中一部分。
- Mekke 最大的问题：作者自己脑补了需求就直接开工，想得太少。Kakatta 先聊透、写清楚再动手。
- Mekke 停止开发，代码原样保留。它的产品设计、频率限制、提示词、数据模型可以借鉴（见 `AGENTS.md`）。

## 为什么不直接用或 fork 参考项目

参考项目：[usagi-org/ai-goofish-monitor](https://github.com/usagi-org/ai-goofish-monitor)，MIT，约 1.9 万 star。Python + FastAPI + Playwright + SQLite，前端 Vue 3.5 + Vite 7 + TypeScript 5.9，Docker 部署，带网页后台。

作者决定自己重写，理由：

- **维护不稳**：提交一阵一阵。2026-03 有 98 个，04 有 18 个，05 有 8 个，06–09 没有提交，10-09 到 10-10 修了 9 个，之后到 2026-11-10 又停了。51 个 issue 没关，有人问「项目是复活了吗」（2026-10-18）。
- **只能服务器部署**：没有桌面端、手机端，也不打算做。
- **重写能吸收它踩过的坑**，不用自己再踩一遍；同时换成作者想要的技术栈。

注：作者认为它技术栈老。核实后它的依赖版本其实是新的，换技术栈的理由是要支持多端和统一语言，不是它过时。
