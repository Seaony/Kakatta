## 2. 「不能接受」的检查项没提到时，哪些要封顶

现在的规则（第 53 条）：态度为「不能接受」的检查项，卖家没提到就最高 89，到不了捡漏。

问题：手机平板品类默认有 7 项「不能接受」（假货、扩容、ID 锁、监管机、网络锁、进水、功能故障），卖家要把 7 项都写到，商品才可能到捡漏。大多数商品做不到，结果是「只推捡漏」基本收不到推送，捡漏的紧急推送也很少触发。「站外交易」「先付定金」两项已经改成只看有没有、没提到不封顶（第 61 条），不在这个问题里。

选项：

- 只有「买到就废、照片看不出来」的几项没提到才封顶：假货、扩容、ID 锁、监管机、网络锁、游戏机被封。进水、功能故障这类没提到不封顶，只放进「联系前问这几句」。（我的推荐）
- 保持现状：所有「不能接受」项没提到都封顶 89。
- 一律不封顶：捡漏最多，但 ID 锁没提到的商品也可能被推成捡漏，只靠「联系前问这几句」提醒。
