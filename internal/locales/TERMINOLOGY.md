# 日文文案约定

短按钮和标题用简洁体，说明和错误提示用です・ます体。保留原因、条件、后果和处理办法，不为缩短文字省掉限制。品牌、协议名、设置键、路径、命令、数字及运行时占位符不翻译；模型生成的结论和卖家原话按原文显示。说明中的字段模板占位符可本地化，例如 `<トークン>`；协议字段和实际执行的命令不改。

| 中文或名称 | 日文 | 用法 |
|---|---|---|
| Kakatta | Kakatta | 不另译项目名 |
| 闲鱼 | 闲鱼 | README 首次写「闲鱼（Xianyu）」；界面保留品牌原字形 |
| 芝麻信用 | 芝麻信用 | 保留服务名称，不把等级改成信用保证 |
| 任务 | タスク | 监控任务及其调度 |
| 监控 | 監視 | 定期搜索的行为 |
| 商品、新商品 | 商品、新着商品 | 不把挂牌价说成成交价 |
| 卖家 | 出品者 | 账号卖家，不用「販売者」混写 |
| 推送、推送渠道 | 通知、通知先 | 渠道类型保留 Telegram、Webhook 等名称 |
| 服务商 | プロバイダー | 模型设置中可写「モデルプロバイダー」 |
| 需求、需求清单 | 購入条件、条件リスト | 按句子区分用户的要求与可编辑清单 |
| 卖家画像 | 出品者の傾向 | 中文「画像」不是日文的图片 |
| 图片 | 画像 | 商品照片及模型图片输入 |
| 证据 | 根拠 | 必须保留引用原文与不确定性 |
| 必须满足、加分项 | 必須条件、加点項目 | 不改变算分规则 |
| 风险、风控 | リスク、アクセス制限 | 商品风险与站点账号限制分开 |
| 冷却、额度 | 待機期間、上限 | 明确是浏览次数还是模型用量 |
| 暂停、恢复 | 一時停止、再開 | 暂停不表示删除或关闭配置 |
| 首次设置 | 初期設定 | 首次打开时设置管理员用户名和密码 |
| 保存、取消、删除 | 保存、キャンセル、削除 | 删除的对象和后果不能省略 |
| 登录、退出登录 | ログイン、ログアウト | Kakatta 和闲鱼账号按上下文注明 |
| 设置、通用、通知 | 設定、一般、通知 | 沿用常见日文界面名称 |
| 两步验证、吊销 | 2段階認証、無効化 | 主动吊销与过期分开 |
| 容器镜像 | コンテナイメージ | 不用商品图片的「画像」 |
| 行情、合理价、挂牌价 | 相場、適正価格、出品価格 | 估算和挂牌记录不保证成交价 |
| 捡漏、划算、价格合理 | 掘り出し物、お買い得、妥当な価格 | 推荐等级采用固定文案 |
| 偏贵或有顾虑、不建议 | 割高・気になる点あり、おすすめしない | 保留价格和风险两个含义 |
| 资源机、验货宝 | 资源机、验货宝 | 保留中国市场的原名，不猜定义；验货宝功能可写「验货宝による検品」 |
| 清除确认口令 | 清除 | 程序要求输入的字面值保持不变，周围说明译为日文 |
| confirm、reject、mind、ignore | 問題なしの明記が必須、問題があれば除外、気になる、気にしない | 确认项保留「必须」含义，不能变成普通说明 |
| 排队、空闲 | 順番待ち、待機中 | 资源排队与任务当前空闲分开 |
| 抓取与限制 | データ取得と制限 | 导航和设置页名称一致 |
| 关于与更新、值得分 | アプリ情報と更新、スコア | 导航、页标题和说明文档一致 |

「价格合理及以上」指推荐等级，写成 `評価が「妥当な価格」以上`，不能写成价格更高。远程闲鱼页面上的实际中文按钮名，如「登录」「保持登录」，在操作说明中保留原字，便于对照画面。

设置和通知的基本用语参考 Apple 日文支持中的[语言设置](https://support.apple.com/ja-jp/guide/mac-help/mh26684/mac)与[通知设置](https://support.apple.com/ja-jp/guide/mac-help/mh40583/mac)。只借用界面用词，不把本项目描述成 Mac 客户端。

字典继续保留 `_one`、`_other` 两个键及同样的参数，日文数量形式可以用同一句。运行时格式化保留现有单次参数替换，不能把参数里的花括号再次解释为模板。参考 [i18next 的复数规则](https://www.i18next.com/translation-function/plurals)。
